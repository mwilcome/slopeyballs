# Slopeyballs

Rooftop platformer. Charge a jump. Glide. Pick a map.

## Play locally

Double-click `index.html`, or refresh if it is already open.

Play → Neon / Coast / Highway. Hold ← → / A D to roll. Hold space to charge a jump; release to pop. Hold jump in the air to glide. Reach the striped sun gate at the end, or fall for tickets. Buy JUMP / GLIDE / SPEED, then ride again. `R` restarts the map. `M` mutes.

`Esc` / `P` pauses or goes back.
